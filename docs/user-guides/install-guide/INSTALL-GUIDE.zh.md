# 1. 你需要准备什么

- **一台运行 Windows 10 或 11 的电脑**（64 位）。
- **网络连接**——用于下载程序和激活许可证。
- **一个许可证密钥**——购买时你会收到。它的格式如下：
  `XXXX-XXXX-XXXX-XXXX-XXXX`（五组，每组四个字符）。
- **大约 10 分钟的时间。**

> 你**不需要**单独安装其他任何东西（例如 .NET）——所需的一切都已包含在安装程序中。

---

# 2. 系统要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| 操作系统 | Windows 10 或 11（64 位） | Windows 10 / 11（64 位） |
| 内存 | 8 GB | 32 GB |
| 磁盘 | 任意 | SSD |
| 可用空间 | 约 500 MB | 1 GB 或更多 |
| 同时运行的账号 | 2 | 4–10 个 CS2 账号 |
| 屏幕分辨率 | 宽度至少 1280 像素 | Full HD（1920×1080）或更高 |

只要你的电脑满足最低要求，应用就能运行。电脑越强劲，你能同时运行的账号就越多。

# 步骤 1. 下载安装程序

1. 打开官方下载页面：
   **[下载 Windows 版](https://github.com/leryqq/farmpanel-releases/releases/latest)**
   （你也可以在 [farmpanel.cc](https://farmpanel.cc) 网站上找到下载链接）。
2. 找到名称类似 **`Setup.exe`** 的文件（如果你在 releases 页面，则在 **Assets** 部分），点击下载。
3. 等待下载完成。文件约 50–80 MB，在快速网络下不到一分钟。

**接下来会发生什么。**`Setup.exe` 文件出现在你的**下载**（Downloads）文件夹中。

> **提示。**只从上面链接的官方页面下载安装程序。这样你得到的是程序真实、经过验证的版本。

![带有 Setup.exe 文件的下载页面](../images/install-download-page.png)

# 步骤 2. 运行安装

1. 打开**下载**文件夹，双击 **`Setup.exe`** 文件。
2. 安装自动开始。**无需管理员权限**——应用仅为你的用户账户安装。
3. 等待完成。通常不到一分钟。没有单独的“下一步”按钮要点——安装程序会自行完成一切。

**接下来会发生什么。**应用完成安装，桌面和开始菜单中出现 **FarmPanel** 图标。应用通常在安装后立即打开。

> **如果出现蓝色的“Windows 已保护你的电脑”（SmartScreen）窗口**——这是新程序的常见警告，并非错误。该怎么做：
> 1. 点击**更多信息**（More info）。
> 2. 点击出现的**仍要运行**（Run anyway）按钮。
>
> 安装照常继续。更多细节见[安装疑难解答](#安装疑难解答)。

# 步骤 3. 打开应用

如果应用没有自行打开，双击桌面上的 **FarmPanel** 图标，或在开始菜单中找到它。

**你会看到什么。**首次运行时，应用会引导你完成一段简短的初始设置和许可证激活——这就是接下来的步骤。

---

# 步骤 4. 初始设置 — Steam 和 Sandboxie 的位置

首次运行时，应用会要求你指出 **Steam** 和 **Sandboxie-Plus** 在电脑上的位置。没有这些路径，应用就无法启动并隔离账号。

> **重要。**到这一步 Sandboxie-Plus 必须已经安装。如果你还没安装，请参见单独的[安装 Sandboxie-Plus](../install-sandboxie-plus/INSTALL-SANDBOXIE-PLUS.zh.md) 指南。

1. **Steam 位置。**点击 Steam 字段旁的文件夹选择按钮（**Browse…** / 文件夹图标），选择 Steam 的安装文件夹。通常是 `C:\Program Files (x86)\Steam`。
2. **Sandboxie 位置。**点击 Sandboxie 字段旁的文件夹选择按钮，选择 Sandboxie-Plus 的安装文件夹。通常是 `C:\Program Files\Sandboxie-Plus`。
3. 确认设置（**Save** / **Continue** 按钮）。

**接下来会发生什么。**应用会记住这些路径，并在每次启动账号时使用它们。

**成功的标志。**两个路径都已设置，且应用不显示找不到 Steam 或 Sandboxie 的警告。

> **提示。**你以后可以随时在 **Settings**（设置）中更改这些路径。

![初始设置 — Steam 和 Sandboxie 的位置](../images/initial-setup-locations.png)

# 步骤 5. 激活你的许可证

激活只需一次——在首次运行时。

1. 在输入框中键入或粘贴你的许可证密钥。
   要从剪贴板粘贴，点击 **Paste from clipboard**（从剪贴板粘贴）。
2. 你键入时，应用会检查密钥格式。格式正确时，激活按钮变为可用。
3. 点击 **Activate**（激活）。

**接下来会发生什么。**应用会联系服务器并验证密钥。这需要几秒钟——你会看到 **Activating**（激活中）状态。

**成功的标志。**激活窗口关闭，应用的主界面——**Dashboard**——打开。你的许可证已激活。以后运行时无需再次输入密钥。

> **如果密钥未被接受**——请确认输入没有拼写错误（最简单的办法是用 **Paste from clipboard** 粘贴），并且你有网络连接。常见提示见[安装疑难解答](#安装疑难解答)。

![许可证激活窗口](../images/license-activation.png)

# 步骤 6. 确认一切正常

激活后，你会进入主界面。请确认安装成功：

1. 窗口顶部可以看到带有各分区的**侧边栏**（**Dashboard**、**Accounts**、**Workflows** 等）。
2. 窗口底部是**状态栏**——一条细窄的条，显示摘要和应用版本（例如 `v1.0.1`）。
3. 应用能够打开，并在各分区之间切换而不报错。

如果这些都具备——**安装完成，你可以开始使用应用了**。

**接下来。**添加你的 Steam 账号并启动你的第一个农场。分步说明请见[用户指南](../user-guide/USER-GUIDE.zh.md)（“核心工作流”部分）。

![安装后的主界面](../images/dashboard-overview.png)

# 更新

FarmPanel **自动**更新——你无需手动下载任何东西。

- 应用在启动时以及运行期间会不时检查是否有新版本。
- 新版本会在后台悄悄下载，不打断你的工作。
- 更新会在应用下次重启时应用。

**你要做的。**没什么特别的。只需时不时关闭并重新打开应用，就会安装最新版本。当前版本始终显示在底部状态栏以及 **Settings → About**（设置 → 关于）中。

# 如何卸载

如果你需要移除 FarmPanel：

1. 打开 **Windows 设置** → **应用** → **已安装的应用**
   （或“控制面板” → “程序和功能”）。
2. 在列表中找到 **FarmPanel**。
3. 点击**卸载**并确认。

**接下来会发生什么。**应用从你的电脑中移除。卸载无需管理员权限。

# 安装疑难解答

以下是常见情况及处理方法。

## 出现“Windows 已保护你的电脑”（SmartScreen）窗口

**原因。**Windows 会对最近下载、系统尚不熟悉的程序显示此警告。这并不表示文件有问题。

**解决办法。**
1. 点击**更多信息**（More info）。
2. 点击**仍要运行**（Run anyway）。

安装继续。如果没有**更多信息**按钮，请确认你是从官方页面下载的文件，然后重试。

## 杀毒软件拦截或删除了文件

**原因。**部分杀毒软件对新的安装程序较为谨慎，可能触发误报。

**解决办法。**
1. 确认你从官方页面下载了 `Setup.exe`（链接见[步骤 1](#步骤-1-下载安装程序)）。
2. 如有需要，把文件加入杀毒软件的排除项，然后重新下载。
3. 如有疑问，请联系支持（见[常见问题](#常见问题)）。

## 浏览器不让下载文件

**原因。**下载 `.exe` 时浏览器也可能较为谨慎。

**解决办法。**在浏览器的下载面板中，选择文件旁的**保留**（Keep）。文件随后会下载完成。

## 双击后安装程序不启动

**解决办法。**
- 确认文件已完整下载（约 50–80 MB）。
- 右键点击文件并选择**打开**。
- 如果文件损坏，请重新下载安装程序。

## 许可证密钥未被接受

| 提示 | 含义 | 该怎么做 |
|---|---|---|
| “License key invalid” | 密钥输入有拼写错误 | 检查拼写。最简单的办法是用 **Paste from clipboard** 粘贴密钥 |
| “Used on max devices” | 许可证已在最大设备数量上使用 | 在另一台设备上释放许可证，然后重试。**Manage devices** 按钮通向设备管理 |
| “Cannot reach license server” | 无法连接服务器 | 检查你的网络连接并点击 **Retry** |

## 安装后应用打不开

**解决办法。**
- 手动打开它：桌面或开始菜单中的 **FarmPanel** 图标。
- 重启电脑再试。
- 若仍无效，请重装应用：先卸载（见[如何卸载](#如何卸载)），再重新安装。

# 常见问题

**安装需要管理员权限吗？**
不需要。FarmPanel 仅为你的用户账户安装，不需要管理员权限。

**我需要单独安装 .NET 或其他组件吗？**
不需要。所需的一切都已包含在安装程序中——只需运行 `Setup.exe`。

**应用安装到哪里？**
安装到你的个人用户文件夹。你无需手动选择文件夹——安装程序会处理好。

**在 SmartScreen 窗口点击“仍要运行”安全吗？**
安全，前提是你从本指南列出的官方页面下载了 `Setup.exe`。出现警告只是因为程序对系统来说是新的。

**安装后我的密码存放在哪里？**
只存放在你的电脑上。它们用 Windows 内置安全机制加密，绝不以明文保存，也绝不外发。

**每次都要输入许可证密钥吗？**
不必。密钥只在首次激活时输入一次。之后应用会直接打开到主界面。

**如何把应用更新到新版本？**
无需任何操作——FarmPanel 会自动更新。只需时不时重启应用，即可安装最新版本（见[更新](#更新)）。

**如果出问题，我该去哪里求助？**
在 Telegram 上联系支持：[t.me/farmpanel_cn](https://t.me/farmpanel_cn)。描述问题，如果有，请附上错误提示的文字。
