# Установка Sandboxie-Plus

**Пошаговое руководство по установке для Windows**

Версия документа: 1.0 · Версия Sandboxie-Plus: **1.17.5**

FarmPanel держит каждый аккаунт в отдельной **песочнице** — изолированном окружении, где Steam и CS2 не пересекаются с другими аккаунтами. За эту изоляцию отвечает бесплатная программа **Sandboxie-Plus**. Её нужно установить один раз перед тем, как запускать аккаунты в FarmPanel.

Это руководство проведёт вас через установку шаг за шагом. Ничего сложного — займёт несколько минут.

> **Коротко.** Скачайте установщик **Sandboxie-Plus 1.17.5** → запустите его → соглашайтесь с настройками по умолчанию → разрешите установку (нужны права администратора) → готово.

> **Важно.** В отличие от самого FarmPanel, Sandboxie-Plus **требует прав администратора** при установке — это нормально, потому что программа встраивается в Windows на глубоком уровне, чтобы надёжно изолировать приложения.

# 1. Что вам понадобится

- **Компьютер с Windows 10 или 11** (64-разрядная версия).
- **Права администратора** на этом компьютере (при установке появится запрос — нужно нажать **Да**).
- **Подключение к интернету** — чтобы скачать программу.
- **Около 5 минут свободного времени.**

> Sandboxie-Plus — бесплатная программа. Часть дополнительных возможностей доступна тем, кто поддерживает проект, но для работы с FarmPanel этого **не требуется** — обычной бесплатной версии достаточно.

# Шаг 1. Скачайте установщик

1. Откройте официальную страницу нужной версии:
   **[Sandboxie-Plus 1.17.5 на GitHub](https://github.com/sandboxie-plus/Sandboxie/releases/tag/v1.17.5)**
2. Прокрутите вниз до раздела **Assets** (Файлы).
3. Найдите и скачайте файл с именем вида **`Sandboxie-Plus-x64-v1.17.5.exe`** — это установщик для обычного 64-разрядного Windows.

**Как выбрать правильный файл:**

| Файл | Кому подходит |
|---|---|
| **`Sandboxie-Plus-x64-v1.17.5.exe`** | **Большинству пользователей** — обычный Windows на процессоре Intel или AMD. Скачивайте этот. |
| `Sandboxie-Plus-arm64-v1.17.5.exe` | Только для компьютеров на процессоре ARM (редкость). |
| `Sandboxie-Classic-…` | Старый вариант интерфейса. Для FarmPanel **не нужен** — берите именно **Plus**. |
| Файлы `.7z` | Портативные версии для опытных пользователей. Для установки **не нужны**. |

**Что происходит дальше.** Файл появляется в вашей папке **Загрузки** (Downloads).

> **Совет.** Скачивайте установщик только с официальной страницы GitHub, ссылка на которую приведена выше. Так вы получите настоящую, проверенную версию.

![страница релиза 1.17.5 с разделом Assets](../images/sandboxie/github-release-assets.png)

# Шаг 2. Запустите установку

1. Откройте папку **Загрузки** и дважды щёлкните по скачанному файлу **`Sandboxie-Plus-x64-v1.17.5.exe`**.
2. Windows покажет запрос **«Разрешить этому приложению вносить изменения на устройстве?»** — нажмите **Да**. Это и есть запрос прав администратора, без него Sandboxie-Plus установить нельзя.

> **Если появилось синее окно SmartScreen** («Windows защитила ваш компьютер») — нажмите **Подробнее**, затем **Выполнить в любом случае**. Это обычное предупреждение для скачанных программ, а не ошибка.

**Что происходит дальше.** Откроется окно мастера установки.

---

# Шаг 3. Пройдите мастер установки

Мастер установки проведёт вас по нескольким простым экранам. В большинстве случаев достаточно оставлять всё по умолчанию и нажимать **Next** (Далее).

1. **Выбор языка.** Если появится окно выбора языка, выберите русский или английский и нажмите **OK**.
2. **Лицензионное соглашение.** Ознакомьтесь и нажмите **I Agree** (Принимаю) или **Next**.
3. **Папка установки.** Оставьте папку по умолчанию (`C:\Program Files\Sandboxie-Plus`) и нажмите **Next**. Менять её не нужно.
4. **Параметры установки.** Ничего менять не требуется — просто нажмите **Next** / **Install** (Установить).
5. Дождитесь окончания. Установка занимает меньше минуты.
6. На последнем экране нажмите **Finish** (Готово). Оставьте включённой галочку запуска Sandboxie-Plus, если она есть.

**Что происходит дальше.** Sandboxie-Plus устанавливается, а на рабочем столе и в меню «Пуск» появляется его значок. Обычно программа запускается сразу после установки.

> **Нужна ли перезагрузка?** Как правило — нет. Но если мастер попросит перезагрузить компьютер, сделайте это, чтобы изоляция заработала корректно.

![экран мастера установки с папкой по умолчанию](../images/sandboxie/installer-wizard.png)

# Шаг 4. Первый запуск Sandboxie-Plus

При первом открытии Sandboxie-Plus показывает **мастер настройки** (Setup Wizard). Пройдите его по шагам — просто повторяйте то, что описано ниже.

Если перед мастером появится окно **выбора языка интерфейса** — выберите нужный язык и нажмите **OK**.

Далее мастер проведёт вас по нескольким экранам.

### Экран 1 — Introduction (Вступление)

Выберите вариант **«Personally, for private non-commercial use»** (Для личного некоммерческого использования) и нажмите **Next** (Далее).

![Setup Wizard — экран Introduction с выбранным «Personally, for private non-commercial use»](../images/sandboxie/wizard-1-introduction.png)

### Экран 2 — Support certificate (Сертификат поддержки)

Оставьте поле **пустым** и нажмите **Next**. Сертификат для работы с FarmPanel не нужен.

![Setup Wizard — экран Support certificate с пустым полем](../images/sandboxie/wizard-2-support-certificate.png)

### Экран 3 — Configure UI (Настройка интерфейса)

Оставьте значения **по умолчанию** (вариант **Advanced UI for experts** уже выбран) и нажмите **Next**.

![Setup Wizard — экран настройки интерфейса со значениями по умолчанию](../images/sandboxie/wizard-3-ui-configuration.png)

### Экран 4 — Shell integration (Интеграция с системой)

**Снимите все галочки** и нажмите **Next**.

![Setup Wizard — экран Shell integration со снятыми галочками](../images/sandboxie/wizard-4-shell-integration.png)

### Экран 5 — Updater (Обновление)

**Снимите все галочки** и нажмите **Next**.

![Setup Wizard — экран Updater со снятыми галочками](../images/sandboxie/wizard-5-updater.png)

### Экран 6 — Complete (Завершение)

Нажмите **Finish** (Готово), чтобы применить настройки и закрыть мастер.

![Setup Wizard — финальный экран с кнопкой Finish](../images/sandboxie/wizard-6-complete.png)

> **Совет.** Если на каком-то экране сомневаетесь — снимайте галочки и жмите **Next**. Для работы с FarmPanel дополнительные интеграции и напоминания об обновлениях не нужны.

**Что происходит дальше.** Открывается главное окно Sandboxie-Plus — список песочниц и панель управления.

![главное окно Sandboxie-Plus после первого запуска](../images/sandboxie/main-window.png)

# Шаг 5. Проверьте, что всё работает

Убедитесь, что Sandboxie-Plus установлен правильно:

1. Откройте Sandboxie-Plus (значок на рабочем столе или в меню «Пуск»).
2. В главном окне виден список песочниц — обычно уже есть песочница по умолчанию с названием вроде **DefaultBox**.
3. Программа открывается и не показывает сообщений об ошибке.

Если всё это на месте — **Sandboxie-Plus установлен и готов к работе**.

# Шаг 6. Свяжите с FarmPanel

После установки Sandboxie-Plus FarmPanel сможет использовать его для изоляции аккаунтов.

1. Откройте **FarmPanel**.
2. Перейдите в **Settings → Sandboxes** (Настройки → Песочницы).
3. Убедитесь, что путь к папке песочниц указан. Если поле пустое, укажите папку для песочниц; если оно уже заполнено — менять ничего не нужно.
4. Вернитесь на экран **Accounts**. Теперь при добавлении аккаунтов можно выбирать способ назначения песочницы (**Auto-assign** и другие), а сами аккаунты можно запускать.

> **Как это связано.** В FarmPanel каждый аккаунт должен быть привязан к песочнице, иначе его нельзя запустить. Именно Sandboxie-Plus создаёт и обслуживает эти изолированные окружения «под капотом». Подробнее о песочницах и запуске аккаунтов — в [Руководстве пользователя FarmPanel](../user-guide/USER-GUIDE.ru.md).

**Признак успеха.** Аккаунт в FarmPanel запускается и переходит в статус **Running** (Работает) — значит, изоляция через Sandboxie-Plus работает.

# Как удалить Sandboxie-Plus

Если нужно удалить программу:

1. Сначала завершите все запущенные в песочницах программы (в FarmPanel — остановите аккаунты кнопкой **Stop**).
2. Откройте **Параметры Windows** → **Приложения** → **Установленные приложения**
   (или «Панель управления» → «Программы и компоненты»).
3. Найдите в списке **Sandboxie-Plus**.
4. Нажмите **Удалить** и подтвердите. Для удаления также нужны права администратора.

> **Обратите внимание.** После удаления Sandboxie-Plus FarmPanel не сможет запускать аккаунты, пока программа не будет установлена снова.

# Устранение проблем

## Windows не даёт установить — нет прав администратора

**Причина.** Sandboxie-Plus обязательно требует прав администратора.

**Решение.** Войдите под учётной записью с правами администратора или попросите администратора компьютера установить программу. При запросе **«Разрешить вносить изменения?»** нажмите **Да**.

## Появилось окно SmartScreen

**Причина.** Windows предупреждает о недавно скачанных программах. Это не ошибка.

**Решение.** Нажмите **Подробнее** (More info), затем **Выполнить в любом случае** (Run anyway).

## Антивирус заблокировал установщик

**Причина.** Некоторые антивирусы осторожно относятся к программам, которые встраиваются в систему.

**Решение.**
1. Убедитесь, что вы скачали файл с официальной страницы GitHub (ссылка в [Шаге 1](#шаг-1-скачайте-установщик)).
2. При необходимости временно добавьте файл в исключения антивируса и скачайте заново.

## Скачал не тот файл

**Причина.** На странице релиза несколько файлов.

**Решение.** Для обычного Windows нужен файл с именем **`Sandboxie-Plus-x64-v1.17.5.exe`**. Не берите варианты **arm64**, **Classic** или архивы **.7z**. Вернитесь к [Шагу 1](#шаг-1-скачайте-установщик) и скачайте правильный файл.

## FarmPanel не запускает аккаунты после установки

**Решение.**
1. Убедитесь, что Sandboxie-Plus установлен и открывается (см. [Шаг 5](#шаг-5-проверьте-что-всё-работает)).
2. В FarmPanel откройте **Settings → Sandboxes** и проверьте, что путь к папке песочниц задан.
3. Перезапустите FarmPanel.
4. Если проблема осталась — обратитесь в поддержку (см. [Частые вопросы](#частые-вопросы)).

## После установки компьютер просит перезагрузку

**Решение.** Перезагрузите компьютер — это завершит установку и включит изоляцию. После перезагрузки снова откройте FarmPanel.

# Частые вопросы

**Обязательно ли ставить Sandboxie-Plus?**
Да, если вы хотите запускать аккаунты в FarmPanel. Именно Sandboxie-Plus обеспечивает изоляцию каждого аккаунта в отдельном окружении.

**Sandboxie-Plus платный?**
Нет, базовая версия бесплатна и её достаточно для работы с FarmPanel. Дополнительные функции доступны тем, кто поддерживает проект, но они не требуются.

**Почему для установки нужны права администратора, а для FarmPanel — нет?**
Sandboxie-Plus встраивается в Windows на глубоком уровне, чтобы надёжно изолировать программы, — поэтому ему нужны права администратора. FarmPanel же устанавливается только для вашего пользователя и таких прав не требует.

**Нужно ли настраивать сами песочницы вручную?**
Нет. Достаточно установить Sandboxie-Plus. Созданием и настройкой песочниц под аккаунты занимается FarmPanel автоматически.

**Нужен ли сертификат поддержки (supporter certificate)?**
Нет. При первом запуске это окно можно пропустить. Для FarmPanel он не нужен.

**Какую именно версию ставить?**
Версию **1.17.5** — ссылка на неё приведена в [Шаге 1](#шаг-1-скачайте-установщик). Устанавливайте именно её для предсказуемой совместимости с FarmPanel.

**Куда обращаться, если что-то не получилось?**
Напишите в поддержку FarmPanel в Telegram: [t.me/farmpanel_ru](https://t.me/farmpanel_ru). Опишите проблему и приложите текст сообщения об ошибке, если он есть.
